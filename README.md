# 甩挂运输交接台

把车辆调度页改造成甩挂运输（牵引车 + 可换挂车）交接台。单页前端，数据保存在浏览器 localStorage，无新增依赖（仅使用既有的 Vue 3 / Vite / TypeScript）。

## 启动

```bash
npm install
npm run dev
npm run build
```

## 业务规则

- **任务单**：填写运输内容、牵引车、挂车、司机、起止时刻。
- **整单校验**：任一命中即整单不通过，输入全部保留，并逐条列出命中项：
  - 挂车处于检修期（日期含端点，与任务日期相交即拦）；
  - 牵引车车牌尾号当日限行（工作日 07:00–20:00，周一 1/6 … 周五 5/0）；
  - 司机剩余可记分不足 3 分；
  - 牵引车 / 司机 / 挂车与在途、待发任务时段重叠；
  - 换挂原"牵引车 + 挂车"组合未确认交回（挂账中不得再派，不看时段）。
- **换挂交接**：先形成交接记录（换下挂车 → 换上挂车、时刻、经办人）；原组合在确认交回前被冻结，不得再次派车。
- **发车冻结**：发车后任务组合与起止时刻不可直接修改；只能换挂或办理回场。
- **回场**：铅封正常 → 正常回场；铅封异常 → 只能"另存带原因修订"，生成修订记录并标记异常回场，原始组合留痕。
- **一致性**：挂车占用由任务 + 交接记录实时派生，刷新后任务、占用、交接、修订完全一致。

## 代码组织（三类关注点分离）

```
src/
├── data/
│   ├── masterData.ts   # 车辆资料：牵引车 / 挂车 / 司机 / 限行规则表
│   ├── storage.ts      # 本地存储层：三类业务数据分键存放
│   └── seed.ts         # 首次进入的演示数据
├── rules/
│   └── rules.ts        # 判定规则（纯函数）：检修 / 限行 / 记分 / 重叠 / 挂账
├── store/
│   └── dispatch.ts     # 响应式状态与写操作编排（派车、发车、换挂、回场）
├── components/         # 派车表单、任务台、挂车看板、交接修订台账、资料看板
├── types.ts            # 领域类型
└── utils/time.ts       # 时间与编号工具
```

localStorage 键：`drop-hook/v1/tasks`、`drop-hook/v1/handovers`、`drop-hook/v1/revisions`，彼此独立。页面底部可恢复演示数据或清空业务数据（车辆资料为静态档案，保留）。
