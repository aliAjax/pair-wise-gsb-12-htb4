# 甩挂运输交接台

- 行业：物流（甩挂运输）
- 技术栈：Vue3、Vite、TypeScript、Pinia，无额外依赖
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则冒烟：`npx vite-node scripts/smoke.ts`、`npx vite-node scripts/flow.ts`

## 功能闭环

1. **派车整单校验**：任务填写牵引车、挂车、司机和起止时刻；以下任一命中即整单不通过，输入全部保留并逐项列出命中项：
   - 挂车检修期与任务时段相交；
   - 牵引车车牌尾号在覆盖日期落入限行映射（工作日 7:00–20:00，跨日逐日判定，挂车不限行）；
   - 司机当前记分达到阈值（12 分制，9 分拦截）；
   - 牵引车 / 挂车 / 司机与未完成任务时段重叠，或“牵引车 + 挂车”原组合存在未确认交回的交接。
2. **换挂交接**：换挂先形成「待确认交回」交接记录，任务当前挂车随之切换、原挂车留痕；原组合确认交回前不得再次派车。
3. **发车冻结**：待发车任务发车后组合冻结，不可取消；正常回场交回释放占用。
4. **异常修订**：回场铅封异常不允许改单，只能另存一条带原因、原/新铅封号的修订记录，原单继续在途冻结。
5. **刷新一致**：任务、挂车占用、交接与修订全部由持久化台账实时推导，localStorage 落盘，刷新后一致；提供“恢复演示数据”。

## 目录组织（资料 / 规则 / 存储分离）

- `src/data/`：车辆资料（牵引车、挂车检修期、司机记分）与台账类型、演示种子；
- `src/rules/`：判定规则纯函数（`validation.ts`）、占用推导（`occupancy.ts`）、时刻工具（`time.ts`），不依赖框架与存储；
- `src/storage/ledgerStore.ts`：localStorage 读写、容错与重置；
- `src/store/dispatch.ts`：Pinia 台账状态，组合规则与存储；
- `src/components/`：派车表单、任务看板、换挂/修订弹窗、交接、占用、修订面板。

数据默认只保存在浏览器 localStorage（键 `dfwlfront-3-drop-hook-ledger-v1`），方便后续替换为接口。
